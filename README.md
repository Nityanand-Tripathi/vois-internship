# 🚗 Car Market Trends Analysis

## 📌 Project Overview

This project analyzes the **CarDekho Used Car Dataset** to understand market trends and identify the key factors associated with used car selling prices.

The analysis focuses on variables such as:

- Manufacturing Year
- Present Price
- Selling Price
- Kilometers Driven
- Fuel Type
- Seller Type
- Transmission
- Number of Previous Owners

The project uses **Python and Exploratory Data Analysis (EDA)** to transform raw data into meaningful insights.

---

## 🎯 Problem Statement

The objective of this project is to analyze the CarDekho used-car dataset and identify the major factors associated with selling price and market trends.

The study examines how vehicle characteristics such as present price, manufacturing year, fuel type, seller type, transmission, mileage, and ownership relate to used-car selling prices.

---
